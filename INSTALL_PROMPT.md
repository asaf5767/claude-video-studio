# הודעה אחת להתקנה

פתחו את Claude Code, הדביקו את ההודעה הזאת ושלחו:

```text
תשתמש בסקיל של הסטודיו לעריכת וידאו מהכתובת הזאת: https://github.com/asaf5767/claude-video-studio — תתקין את כל מה שצריך, תשאל אותי לפני כל התקנה, ותסביר לי בעברית פשוטה מה אתה עושה. כשהכל מוכן, תפתח לי את הסטודיו בדפדפן.
```

Claude קורא את ההוראות שבראש [README.md](README.md), מוריד את הסטודיו לתיקייה שתבחרו,
ועובד לפי הסקיל `.claude/skills/setup-studio/SKILL.md`: בודק מה חסר, שואל לפני כל התקנה,
ובסוף פותח את הסטודיו בדפדפן. ההודעה לא צריכה שינוי כשיוצאת גרסה חדשה.

כבר יש לכם את התיקייה? פתחו בה את Claude Code וכתבו `/setup-studio`.
בלי הסקיל אפשר לעבוד לפי [SETUP.md](SETUP.md).

# One message to install

Open Claude Code, paste this message and send it:

```text
Use the video studio skill from https://github.com/asaf5767/claude-video-studio — install everything it needs, ask me before each install, and explain in plain English what you're doing. When it's ready, open the studio in my browser.
```

Claude reads the instructions at the top of [README.en.md](README.en.md), downloads the studio
into the folder you choose and follows the `.claude/skills/setup-studio/SKILL.md` skill: it checks
what is missing, asks before each install and finally opens the studio in your browser. The
message never needs editing when a new version ships.

Already have the folder? Open Claude Code in it and write `/setup-studio`.
Without the skill, follow [SETUP.md](SETUP.md).
